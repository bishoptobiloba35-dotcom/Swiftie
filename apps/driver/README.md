# SwiftDrop Driver App

Planned production React Native/Expo app for approved drivers.

Core screens:
- Registration and KYC
- Driver approval status
- Online/offline
- Nearby delivery requests
- Job details
- Navigation/pickup
- Mandatory parcel photograph
- Start trip
- Background GPS tracking
- Receiver PIN verification
- Earnings and withdrawals
- Incident reporting

The backend remains authoritative for delivery status and payout eligibility.
